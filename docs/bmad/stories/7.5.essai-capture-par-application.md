# Story 7.5 — Essai : capture par application (process loopback)

**Statut :** Draft (après le MVP 7.1 à 7.4), plafonnée à une demi-journée
**Epic :** 7

## Question à trancher

La capture Windows par application, en mode « toutes les applications sauf Meetily » (`AUDIOCLIENT_PROCESS_LOOPBACK_PARAMS`, `PROCESS_LOOPBACK_MODE_EXCLUDE_TARGET_PROCESS_TREE`, Windows 10 build 20348 ou plus récent), enregistre-t-elle le son de Teams **quelle que soit la sortie** ? Cela vaut aussi pour le nouveau Teams, qui tourne dans WebView2.

## Critères de réussite de l'essai

1. Un petit programme Rust isolé capture 20 s pendant que Teams, puis un navigateur, jouent successivement sur le Jabra et sur les haut-parleurs.
2. Le niveau capté est non nul dans les deux cas, et Meetily n'est pas capté.
3. Conclusion écrite dans cette story : intégrer (le moteur de « Automatique » devient la capture par application) ou abandonner, avec la raison.
